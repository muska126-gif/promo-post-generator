# 📣 促銷貼文產生器

把當期促銷 PDF 拖進來，自動產出 **FB / IG / LINE** 三平台貼文與圖卡。

單一 HTML 檔、無需安裝、無需伺服器、直接雙擊瀏覽器打開就能用。

---

## 🚀 快速上手

**線上版**（需連網載入 pdf.js、html2canvas 兩個外部 lib）：
- 下載 `促銷貼文產生器_v3.html`（約 80 KB）
- 雙擊開啟

**離線版**（所有依賴內嵌，斷網可用）：
- 下載 `促銷貼文產生器_離線版_v3.html`（約 2 MB）
- 雙擊開啟

兩版功能完全一樣。

---

## ✨ 主要功能

- **PDF 自動解析**：上傳促銷 PDF，自動抓出商品名稱、規格、價格
- **系列自動分類**：iPhone / Mac / iPad / Apple Watch / 配件 五大類
- **三平台模板**：FB（詳盡）、IG（含 hashtag）、LINE（精簡）三種語氣
- **兩種文案風格**：活潑小編風 vs 專業理性風，可即時切換
- **多規格價格列表**（專業風）：`256GB $28,486、512GB $35,066` 一目了然
- **合併分類貼文**：一鍵把「所有 Mac 產品」合併成單一貼文
- **PNG 圖卡匯出**：個別產品 1080×1080 方形圖、合併分類直式圖，含三平台配色
- **內建 291 家 TK3C 門市資料**：輸入店號自動帶入店名、電話、地址
- **文案素材庫可編輯**：頁面內直接改 hook / sell 句、匯出/匯入 JSON 備份
- **所見即所得**：貼文產生後可直接編輯，重新產生也可

## 🖱️ 操作流程

1. **上傳促銷 PDF**（或純文字 .txt）
2. **選擇要產生的系列**（自動偵測 → 用 chips 勾選 / 或點分類按鈕批次選）
3. **設定活動期間**（會從檔名自動抓 `MMDD` 格式）
4. **輸入店號**（例如 `219` → 自動帶出內湖旗艦店資訊）
5. **選文案風格**（活潑 / 專業）
6. **產生貼文** → 每個平台一則、可即時編輯
7. **匯出**：CSV / Markdown / PNG 圖卡

---

## 🎨 頁面編輯

- 點任何一則貼文的文字區域可直接修改
- 「🔄 重新產生」把該則貼文重跑一次（會覆蓋手動編輯）
- 「📋 複製」一鍵複製到剪貼簿貼進 FB / IG / LINE

---

## ⚙️ 進階：自訂文案素材庫

1. 展開「③ 文案素材庫」→「📝 編輯文案」
2. 修改任一系列的 Hook（吸睛開頭）與 Sell（賣點描述）
3. 自動存到瀏覽器 localStorage，關掉重開仍在
4. 用「💾 下載 JSON」備份、「📥 載入 JSON」在別台電腦還原

## 🛠️ 技術細節

- **前端 only**：純 HTML/CSS/JavaScript，無後端
- **資料處理全在瀏覽器**：上傳的 PDF **不會**送到任何伺服器
- **儲存位置**：文案設定與店號記憶都用 localStorage，只存在瀏覽器內

**依賴**：
- [pdf.js](https://mozilla.github.io/pdf.js/) — PDF 解析
- [html2canvas](https://html2canvas.hertzen.com/) — PNG 匯出

---

## 🔒 隱私

- **門市資料**：僅含公開資訊（店名、公開電話、地址），共 291 家
- **無個人資料**：不含店經理姓名、手機、分機、MIS 代碼
- **PDF 內容**：不上傳、不外送、關掉瀏覽器就消失
